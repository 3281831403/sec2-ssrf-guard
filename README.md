图片抓取接口允许填任意地址，攻击者填了一个内网地址，把云上的元数据接口读了出来：目标地址必须解析成 IP 后再判断，不得只看字符串；内网与保留网段一律拒绝；重定向后的最终地址必须重新校验；DNS 解析结果与连接用的地址必须一致；只允许白名单协议与端口；不得允许指向本机回环；批量校验各目标独立。不变量：任何能访问内网的目标都被拒绝；同一输入两次校验结果相同。

## 运行方式

在仓库根目录执行：

    python -m pytest tests -q

公开测试共五条，初始状态全部失败。测试不联网，也不依赖随机数；主机名到地址的映射、以及实际发起连接的动作用测试注入的回调代替。

实现者只能补全实现代码，不得修改测试、删减测试、跳过测试或放宽断言。

## 接口约定

八个入口分别负责：解析目标、解析主机、判定地址、判定协议与端口、校验单个目标、校验重定向链、检查策略、批量校验。判定类入口返回布尔值，True 表示放行；策略检查返回问题描述列表，空列表表示策略可用；批量入口返回目标到布尔值的映射。

策略是字典，可包含以下键：

- schemes：允许的协议，缺省为 http 与 https。
- ports：允许的端口，缺省为 80 与 443；显式写成空值或 any 表示不限制。
- max_redirects：允许跟随的重定向跳数。
- block_private：是否启用内网拦截。
- resolver：主机名到地址列表的回调，缺省使用系统解析。
- dial：连接钩子，收到已经校验过的地址与端口，缺省不发起连接。

解析入口返回包含 ok、scheme、host、port、path 五个键的字典；ok 为假时其余字段为空值。

## 校验规则

- 判定依据是解析出的地址，主机名的字面只当作名字。
- 同一个目标只解析一次，连接钩子拿到的必须是参与判定的那个地址。
- 无法解析的地址和无法解析的主机名一律按拒绝处理；重定向链为空时同样拒绝。
- 地址判定覆盖内网、保留网段、回环、链路本地与组播。
- 重定向链上的每一跳都按单个目标处理。
- 策略检查覆盖内网规则、端口范围与重定向处理。
